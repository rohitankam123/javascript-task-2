A collection of **30 JavaScript practice questions** covering variables, data types, operators, type casting, conditions, switch statements, loops, and mixed practice.

## 📌 Part 1: Variables and Data Types

### 1. Variables – `var`, `let`, and `const`

- Subtraction

### 7. Increment Operator

Predict the output:

```javascript
let a = 5;

console.log(a++);
console.log(a);
console.log(++a);
```

---

### 8. Decrement Operator

Predict the output:

```javascript
let a = 10;

let b = a--;
let c = --a;

console.log(a);
console.log(b);
console.log(c);
```

---

### 10. Comparison Operators

